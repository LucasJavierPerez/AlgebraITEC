## Cómo actualizar el sitio

Este repo es una copia del material publicable. Para actualizar una unidad,
copiá el archivo nuevo sobre el que corresponde en `unidades/` o `notebooks/`,
y hacé commit y push. GitHub Pages republica solo, en un minuto o dos.

## Notas técnicas

- Las páginas de unidad son HTML autocontenido: no dependen de nada del repo
  salvo Google Fonts, que se carga desde internet.
- `.nojekyll` desactiva el procesamiento de Jekyll, que no hace falta acá y
  puede ignorar archivos que empiezan con guión bajo.
