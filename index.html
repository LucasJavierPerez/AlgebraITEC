Cuál abrir

Leer la unidad — el apunte de la clase, con explicaciones y demos para tocar. Es por donde conviene empezar.

Notebook interactivo — el notebook corriendo de verdad dentro del navegador: movés los controles y el código se vuelve a ejecutar. No hay que instalar nada. La primera carga tarda entre 20 y 30 segundos porque baja Python al navegador; después va fluido.

Ver el notebook — el notebook de Jupyter como página web, con el código y los resultados ya calculados. Para leer, no se ejecuta.

Descargar .ipynb — para abrirlo en Jupyter, VS Code o Google Colab y modificarlo. Necesitás numpy y matplotlib.
