Varias casas apiladas. Una matriz es una tabla: cada fila es una observación, cada columna una característica. Es literalmente tu dataset.

No es "tres imágenes" apiladas — es una sola imagen en tres capas. Cada capa dice cuánto rojo, verde o azul hay en cada píxel. Recién cuando mirás las tres capas juntas, en la misma posición, aparece el color real.

¿Por qué los datos son arrays?

Un CSV es solo números ordenados

Cuando abrís un archivo con datos de 500 casas, lo que realmente tenés son números organizados en filas y columnas. Esa organización tiene nombre según cuántas "capas" de estructura tenga.

1D = vector = una fila 2D = matriz = una tabla 3D+ = tensor = varias tablas

La herramienta que usa Python para manejar todo esto:

numpy.ndarray

N-dimensional array. Aprender a construirlo, mirarlo y recortarlo es la habilidad más usada de toda la materia.

NumPy vs. listas de Python

¿Por qué no alcanza con una lista?

Python ya trae listas. Pero para procesar números en volumen, NumPy hace el mismo trabajo de forma mucho más rápida y ordenada.

Lista de Python

  • Recorre los datos de a uno, así que es lenta con volúmenes grandes.
  • Guarda cada número como un objeto separado — ocupa más memoria.
  • No es compatible con las librerías de Machine Learning.

NumPy array

  • Aplica la operación a todos los números a la vez — mucho más rápida.
  • Guarda los datos de forma compacta, con un solo tipo fijo.
  • Es la base de todas las librerías de ML: scikit-learn, PyTorch, TensorFlow.

Reshape y flatten

Cambiar la forma sin cambiar los datos

flatten() convierte cualquier array a una sola fila. reshape() hace el camino inverso: reorganiza esos mismos números en la forma que necesites. El -1 le dice a NumPy "calculá vos esta dimensión".

dataset (5, 4)

→ .flatten() →

x_flat (20,)

→ .reshape(10, 2) →

(10, 2)
